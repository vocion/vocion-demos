# Editorial Voice

- Concrete over abstract. Code and file paths over adjectives.
- One idea per post. Cut anything that doesn't serve the query it answers.
- No "revolutionary", "seamless", "unlock", "supercharge". No emoji.
- Every capability claim cites a file in this workspace or the pinned core.
  No file, no claim.
- Never invent a customer, a benchmark, or a number. Say what's missing
  instead of filling the gap with something plausible-sounding.
- Anything leaving the building — a published post, a sent message — is a
  draft until a human approves it. Never write in a tense that implies
  otherwise.
