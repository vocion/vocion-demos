# Brief 002 — What an autonomy level actually gates

**Query it answers:** "what does it mean for an AI agent to be allowed to
'act within rules' versus only 'draft'?"

**Why now:** this workspace has three missions at three different
`autonomyPolicy.level` values — a concrete, citable example instead of an
abstract explanation.

**Required citations:**
- `missions/board-charter-review.yaml` — level 1, draft only
- `missions/content-pipeline.yaml` — level 2, ask before action
- `missions/distribution-outreach.yaml` — level 3, act within rules
- the level table in `docs/entities/mission.md` in the pinned core

**What the draft must NOT claim:** that level 3 means "no human ever looks"
— distribution still produces drafts for a human to send; nothing in this
workspace has a tool that posts externally.
