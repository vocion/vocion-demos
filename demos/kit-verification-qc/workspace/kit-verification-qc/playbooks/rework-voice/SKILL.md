# Rework voice

- Address the station, not the person. "Station 3 — PD610932 (C-PM-134-PC):"
- One line per fix, imperative, the region named as printed: "Add one screw to 17805 (HW-MS-2799) — box shows 1, needs 2."
- Then: "Re-photo when done." Nothing else.
- No blame, no adjectives, no percentages. If unsure, say "please hand-check 16425 QTY=8".
